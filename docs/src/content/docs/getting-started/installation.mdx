title: Installation
description: Install Claudio using Docker or Docker Compose.
---

## Docker

```bash
docker run -d \
--name claudio \
-e PUID=1000 -e PGID=1000 \
-p 8080:8080 \
-v /path/to/games:/games \
-v claudio-data:/config \
ghcr.io/lmrisdal/claudio:latest
```

Open `http://localhost:8080` to start using Claudio.

## Docker Compose

```yaml
services:
  claudio:
    image: ghcr.io/lmrisdal/claudio:latest
    container_name: claudio
    ports:
      - "8080:8080"
    volumes:
      - claudio-data:/config
      - /path/to/games:/games
    environment:
      - PUID=1000
      - PGID=1000
      - CLAUDIO_IGDB_CLIENT_ID=your_client_id
      - CLAUDIO_IGDB_CLIENT_SECRET=your_client_secret

volumes:
  claudio-data:
```

## Docker Compose with PostgreSQL

```yaml
services:
  claudio:
    image: ghcr.io/lmrisdal/claudio:latest
    container_name: claudio
    ports:
      - "8080:8080"
    volumes:
      - claudio-data:/config
      - /path/to/games:/games
    environment:
      - PUID=1000
      - PGID=1000
      - CLAUDIO_DB_PROVIDER=postgres
      - CLAUDIO_DB_POSTGRES=postgres://claudio:secret@db/claudio
    depends_on:
      - db

  db:
    image: postgres:18-alpine
    container_name: claudio-db
    volumes:
      - postgres-data:/var/lib/postgresql/data
    environment:
      - POSTGRES_DB=claudio
      - POSTGRES_USER=claudio
      - POSTGRES_PASSWORD=secret

volumes:
  claudio-data:
  postgres-data:
```

## Data Persistence

Claudio stores its database and settings in the `/config` directory. Make sure the `/config` volume is persistent.
